System Preparation Checklist

  1. Structure quality: Check for missing atoms, alternate conformations, steric clashes (MolProbity). Resolve with modeling tools (Modeller, Rosetta, PDBFixer).
  2. Protonation states: Assign at target pH (H++, PROPKA, H++). Key: His (HID/HIE/HIP), Asp/Glu, Lys, N/C-termini. For constant pH MD, use λ-dynamics.
  3. Cofactors/ligands: Parametrize with GAFF2/CGenFF/OPLS. Validate charges (RESP/AM1-BCC), torsions (scan vs. QM), and bonded parameters.
  4. Solvation: Box padding ≥ 1.0 nm (1.2 nm for charged systems). Use appropriate water model matching force field (TIP3P for AMBER/CHARMM, SPC/E for GROMOS, OPC/TIP4P-Ew for accuracy).
  5. Ions: Neutralize + physiological concentration (150 mM NaCl). Place with Monte Carlo (genion) to avoid clashes. Use ion parameters consistent with water model (Joung-Cheatham for TIP3P).

Energy Minimization

  • Algorithm: L-BFGS (fast, robust) or steepest descent (for severe clashes). Conjugate gradient is slower and rarely needed.
  • Convergence: Max force < 100–500 kJ/mol/nm (10–50 kJ/mol/nm for production prep). Energy should plateau.
  • Restraints: Heavy-atom restraints (1000 kJ/mol/nm²) during initial minimization of solvent; then unrestrained.
  • Check: No "LINCS/SHAKE warnings" after minimization; no extreme energies.

Production Run Setup

  • Ensemble: NVT (fixed density, better for free energy) or NPT (correct pressure). Use NPT for final equilibration, then NVT for production if density is stable.
  • Thermostat: CSVR or NHC (τT = 1–5 ps). Avoid Langevin for production unless implicit solvent or specific need for stochastic dynamics.
  • Barostat (NPT): MTTK (τP = 5–20 ps). Semi-isotropic for membranes.
  • Time step: 2 fs (H-bonds constrained), 4 fs (HMR + all bonds constrained). Validate energy conservation in short NVE test.
  • Constraints: LINCS (GROMACS) or SHAKE (AMBER/NAMD/CHARMM). All bonds constrained for 4 fs; H-bonds only for 2 fs. SETTLE for water.
  • Cutoffs: 1.0–1.2 nm for LJ and real-space electrostatics. PME grid ≤ 0.12 nm. Force switch for LJ. Dispersion correction ON.
  • Output frequency: Coordinates every 10–100 ps (balance storage vs. resolution). Energies every 1–2 ps. Compressed trajectory formats (xtc, dcd, netcdf).

Reproducibility & Documentation

  • Version control: Git for all scripts, input files, analysis code.
  • Software versions: Record MD engine (GROMACS/AMBER/NAMD/LAMMPS version), force field version, water model, compiler, GPU driver.
  • Random seeds: Set and record seeds for velocity generation, Langevin/Andersen, REMD exchanges. Enables exact reproduction.
  • Input files: Archive .mdp/.in/.inp files, topology, coordinates, parameter files.
  • Metadata: Use standardized formats (e.g., YAML/JSON) for simulation metadata: system composition, force field, ensemble, time step, cutoffs, thermostat/barostat parameters.
  • Data management: Store raw trajectories (or representative subsets) in institutional repositories. Use compressed formats.

Performance Optimization

  • GPU acceleration: Use CUDA/OpenCL/HIP builds. Single GPU often > 10 CPU cores. Multi-GPU with domain decomposition (GROMACS, AMBER, NAMD, LAMMPS).
  • Mixed precision: FP32 for accumulation, FP16/TensorFloat-32 for computation. Default on modern GPUs; verify energy conservation.
  • Domain decomposition: Balance load across MPI ranks/GPUs. Tune PME grid, cutoff, and DD cell size.
  • Hydrogen Mass Repartitioning: 4 fs time step with minimal artifacts for structural/thermodynamic properties.
  • Trajectory compression: Write xtc/dcd with precision 1000 (0.001 nm) or use lossy compression (zstd, blosc) for archival.

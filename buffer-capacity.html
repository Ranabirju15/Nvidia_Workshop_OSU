Differential Buffer Capacity: Rigorous Definition

The buffer intensity (Van Slyke buffer capacity) is defined as: 

β = dCb/dpH = −dCa/dpH

For a solution containing multiple weak acid/base systems and strong electrolytes, the general expression is: 

β = 2.303 ( [H⁺] + [OH⁻] + Σi Ci Ka,i[H⁺] / (Ka,i + [H⁺])² )

where the sum runs over all weak acid systems i with total concentration Ci and acid dissociation constant Ka,i. The three contributions are:

  1. [H⁺] — Strong acid contribution (dominant at low pH)
  2. [OH⁻] — Strong base contribution (dominant at high pH)
  3. Σ Ci Ka,i[H⁺]/(Ka,i+[H⁺])² — Weak acid/base buffering

Each weak acid contributes a bell-shaped curve centered at pKₐ,i with maximum βmax,i = 0.576 Ci (since max of x/(1+x)² = ¼ at x=1, and 2.303/4 = 0.576).

Buffer Capacity of Polyprotic & Mixed Systems

For a diprotic acid H₂A (e.g., carbonic acid, pKₐ₁=6.35, pKₐ₂=10.33), the capacity is the sum of two terms: 

β = 2.303 ( [H⁺] + [OH⁻] + Ctot ( Kₐ₁[H⁺]/(Kₐ₁+[H⁺])² + Kₐ₂[H⁺]/(Kₐ₂+[H⁺])² ) )

If pKₐ₂ − pKₐ₁ > ~3, the two buffering regions are distinct. If closer (e.g., citric acid pKₐ₁=3.13, pKₐ₂=4.76, pKₐ₃=6.40), the peaks merge into a broad plateau. This is exploited in universal buffers (e.g., Britton–Robinson).

For mixed buffers (different acid systems), total β is additive if no cross-reactions occur. This allows designing buffers with flat capacity over a wide pH range (e.g., 0.04 M each of citric, phosphoric, boric acids).

Buffer Capacity in Open vs. Closed Systems

The carbonate/bicarbonate system (pKₐ₁' = 6.1 for CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻) behaves differently in open (gas exchange) vs. closed systems: 

Closed: β = 2.303 ( [H⁺] + [OH⁻] + Ctot Kₐ[H⁺]/(Kₐ+[H⁺])² )
Open (constant PCO₂): β = 2.303 ( [H⁺] + [OH⁻] + [HCO₃⁻] )

In an open system (e.g., blood), β is nearly constant over a wide pH range because [HCO₃⁻] adjusts via CO₂ exchange. This is why blood has high effective buffer capacity despite low total bicarbonate.

Numerical Buffer Design

Modern buffer preparation uses numerical speciation solvers (e.g., PHREEQC, Visual MINTEQ, or custom Python). Given target pH, ionic strength, temperature, and total concentration, one solves the full equilibrium for required component masses. Example algorithm: 

# Given: target pH, C_tot, T, I_estimate
pK_a(T) = pK_a(25°C) - (ΔH°/2.303R)(1/T - 1/298.15)
r = 10^(pH - pK_a(T))
# Iterate: compute I from concentrations, update γ, recompute r

This accounts for temperature, activity, and all protonation states simultaneously.
